Phantom Calc is a web-based calculator that helps Phantom participants to estimate how many hours they need to redeem their desired prizes from the
Phantom Shop. Just choose the prizes you want and see how many hours you need to code to get there. Good Luck!

# How to use it
Just clone this repo with ```git clone https://github.com/Manas-909/Phantom-Calc``` and open the index.html file inside the downloaded folder
or you can check it out [here](https://phantom-calc.vercel.app/).
